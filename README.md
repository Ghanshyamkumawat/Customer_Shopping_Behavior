# 🛍️ Customer Shopping Behavior Analysis

A data analytics project that analyzes customer shopping behavior using **Python, MySQL, SQL, and Power BI**. The project focuses on cleaning, transforming, and analyzing customer transaction data to identify purchasing patterns, customer demographics, and business insights through an interactive dashboard.

---

## 📌 Project Overview

This project demonstrates the complete data analytics workflow:

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- SQL Database Integration
- Business KPI Analysis
- Interactive Power BI Dashboard
- Customer Behavior & Sales Insights

The dataset contains **3,900+ customer transaction records** with information such as customer demographics, product purchases, payment methods, shopping frequency, and ratings.

## ▶️ How to Run

### 1. Clone Repository

```bash
git clone https://github.com/Ghanshyamkumawat/Customer_Shopping_Behavior.git
```

### 2. Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql
```

### 3. Open Jupyter Notebook

Run:

```bash
jupyter notebook
```

Execute notebooks in order:

- Data Cleaning
- EDA
- MySQL Integration

### 4. Import SQL File

Import the SQL script into MySQL Workbench.

### 5. Open Power BI Dashboard

Open the `.pbix` file using **Power BI Desktop**.
